# Third-party notices and data attribution

## MapLibre Native

The application uses MapLibre Native for Android (`org.maplibre.gl:android-sdk`). MapLibre Native is distributed under the BSD 2-Clause license. See <https://github.com/maplibre/maplibre-native>.

## OpenFreeMap / OpenMapTiles / OpenStreetMap

The initial online vector style uses the OpenFreeMap public style and tile infrastructure with an original application-side style definition. OpenFreeMap tiles are based on OpenStreetMap data and the OpenMapTiles schema.

Map data © OpenStreetMap contributors, available under the Open Database License: <https://www.openstreetmap.org/copyright>.

OpenMapTiles schema and licensing information: <https://openmaptiles.org/about/terms/>.

OpenFreeMap project and usage information: <https://openfreemap.org/>.

MapLibre attribution controls remain enabled on the projected map. Offline support must use an appropriately licensed tile package; the application must not bulk-download from OpenStreetMap's public raster tile servers.

## Fonts and artwork

The current car surface uses host typography and the map provider's Noto Sans glyph endpoint. Application icons, map styling, telemetry artwork, and phone-side abstract terrain artwork are original project assets.
